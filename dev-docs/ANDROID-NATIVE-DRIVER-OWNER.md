# Native GL driver state owner

NativeDriverState contains the existing PVRTC/palette/anisotropy caches, filtered extension CString, opening-fog guard and deferred context error. It holds no SDL window/context, Environment or guest memory. The compiler checks Send for owned migration via for_owner(); no unsafe Send/Sync is introduced and this does not permit sharing GL state or Environment. GLES1NativeContext retains its SDL context/loading flag and synchronously borrows this state as before. Context error storage persists across all borrows.

initialize_current() must run on the current GL owner's thread after binding functions; capability/PVRTC checks remain once per state. borrow_native() produces a lifetime-limited local dispatcher. The ordinary path still executes on the game owner: this extraction is a prerequisite for a worker-owned renderer, not an activated threaded game or performance gain. Compatibility draw/fog/light functions, texture formats, native input/UI and all defaults are unchanged. Full actor work still requires every GL/present operation to have one owner, copied client geometry, resource/query barriers and native input latency/correctness tests.

The owned-packet precursor is ds_vertex_snapshot.rs (not yet connected to the game dispatcher). Standalone rustc --test covers96 client/VBO stride/index rebase cases, source mutation/reallocation after enqueue across a thread, and bounds/budget/overflow native-fallback cases. Only u16 fixed-function indices are currently modeled. Real GPU packet replay, other index forms, resource/query/present ordering and full actor integration remain open.
